# Turistuble MVP v12

Sitio estático HTML5 + CSS3 + JavaScript + JSON.

Cambios v12:
- Buscador simplificado: ¿Qué buscas?, comuna y categoría.
- Se eliminaron filtros de provincia y tipo de la home.
- Carrusel publicitario con alto fijo para evitar saltos visuales al cambiar de slide.
- Se mantiene ficha con carrusel, cards con primera imagen y JSON como fuente de datos.

## Ejecutar local

```bash
npm install
npm start
```

Abrir: http://localhost:3000
